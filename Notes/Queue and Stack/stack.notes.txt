=================== TECHNIQUES ===================
1. Next greater/Next smaller | Monotonic
    Notes:
    -> the stack holds the elements still waiting for an answer
    -> O(n) runtime because the items can at most be touched 2n times (push and pop)
    -> store the indices 

    Problems: 
    -> daily temperature [done]
    -> next greater element I/II [done]
    -> stock span [done]
    -> largest rectangle in histogram 
    -> trapping rain water 
    -> remove k digits | duplicate letters

    Variants:
    -> next greater: pop while stack top smaller than current
    -> next smaller: pop while stack top greater than current
    -> previous greater: pop while stack top is smaller than current (read the survivor) 
    -> previous smaller: pop while stack top is greater than current (read the survivor)

    next X -> reads the answer off the element being popped 
    previous X -> reads the answer off the element still on top afterwards
