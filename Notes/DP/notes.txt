=================== DP PROPERTY
- Optimal substructure 
- Overlapping subproblem

Top-Down (Memoization)
Bottom-Up (Tabulation)

1. Identify recurrence relation
2. Identify the base case 
3. Write recursive solution
4. Add memoization
5. Convert to bottom-up DP

BASE CASES go into memo cache (as default placements)

Identification Signals 
"number of ways to..."      → counting DP
"minimum/maximum cost to..."→ optimization DP
"is it possible to..."      → boolean DP
"longest/shortest..."       → sequence DP
overlapping subproblems     → memoize!
optimal substructure        → DP works!

====================== NOTES
dp indices represent STEPS 0 through n inclusive hence why tabulation tables usually include n + 1 spaces

Backtracking (brute force, identify subproblems)
      ↓
Is greedy applicable?
   YES → Greedy (O(n log n) usually)    STOP HERE if optimal
   NO  ↓
Memoization (top-down DP)
      ↓
Tabulation (bottom-up DP)
      ↓
Space Optimized


====================== STUDY PLAN 
Break problem into OVERLAPPING subproblems
Store results to avoid recomputation

Two approaches:
Top-down    → recursion + memoization (cache results)
Bottom-up   → tabulation (build from base cases up)

Key question: "Have I solved this subproblem before?"

The DP Recipe (Apply to Every Problem)
Step 1: Define state    → "what does dp[i] represent?"
Step 2: Recurrence      → "dp[i] = f(dp[i-1], dp[i-2]...)"
Step 3: Base cases      → "dp[0] = ?, dp[1] = ?"
Step 4: Traversal order → "left to right? diagonal?"
Step 5: Extract answer  → "return dp[n]? max(dp)?"

Day 4 — Knapsack DP

Goal: master the most common DP pattern

Theory:
0/1 Knapsack    → each item used AT MOST once
Unbounded       → items can be reused freely

0/1 recurrence:
dp[i][w] = max(dp[i-1][w], dp[i-1][w-weight] + value)

Unbounded recurrence:
dp[w] = max(dp[w], dp[w-weight] + value)

Problems:
1. LC 416  Partition Equal Subset Sum  ← 0/1 knapsack
2. LC 494  Target Sum                  ← 0/1 knapsack
3. LC 322  Coin Change                 ← unbounded
4. LC 518  Coin Change II              ← unbounded
5. LC 474  Ones and Zeroes             ← 2D knapsack

Key question per problem:
"Can I reuse items? → determines knapsack variant"

Expected complexity:
All problems → O(n × W) time, O(W) space optimized

Day 5 — Interval DP

Goal: apply DP to interval problems

Theory:
dp[i][j] = optimal solution for interval [i,j]
Try all split points k → dp[i][j] = f(dp[i][k], dp[k][j])
Build from SMALLER intervals to LARGER

Problems:
1. LC 647  Palindromic Substrings
2. LC 516  Longest Palindromic Subsequence
3. LC 312  Burst Balloons
4. LC 1039 Minimum Score Triangulation
5. LC 375  Guess Number Higher or Lower II

Key question per problem:
"Where do I split the interval?"

Expected complexity:
All problems → O(n³) time, O(n²) space
